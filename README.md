# NovelCraft 小说工坊 (基于 Tauri v2 + React)

一个专为网络小说与文学创作者设计的**「逆向拆解 ➔ 灵感迁移 ➔ 仿写实战 ➔ AI 审稿」**全闭环本地桌面工具。

---

## 🌟 核心功能闭环

1. **研习拆解坊 (Deconstruct)**
   - **极速本地解析**：Rust 高性能正则秒级切分全本小说章节，内存占用低至几十 MB。
   - **深度逆向解构**：提取核心剧情事件摘要、留存悬念钩子（Hook）、登场人物动机、世界观法则词条与名家写作技法。
   - **张力打分体系**：基于情绪曲线为每章的戏剧冲突打分（1-10分）。

2. **脑洞生成库 (Brainwave)**
   - **故事骨架迁移**：提炼优秀作品的底层逻辑公式（如《诡秘之主》第一卷结构），输入新题材（如赛博修真、末日道法），自动推演全套新书立项设定。
   - **金手指代价机制**：自动生成带强反噬规则与成长限制的爽点体系。
   - **三幕式大纲演化**：自动规划【起·承·转·合】的核心节拍点。

3. **仿写创作台 (Drafting & Imitation)**
   - **双栏对照写作**：左侧提供参考小说的对应节拍、黄金开局法则与技法笔记，右侧进行沉浸式分章写作。
   - **实时字数统计与一键送审**。

4. **AI 审稿评估室 (Review & Critique)**
   - **多维度商业评估**：对标爆款网文黄金法则，生成开篇钩子强度、节奏张力、追读欲望、设定新鲜度与人物弧光五维雷达评估。
   - **毒点硬伤排查**：明确指出拖沓灌水、人物出戏等硬伤。
   - **实操改稿方案**：金牌主编级别的具体润色和调整建议，切实检验学习与仿写成效。

## 🚀 启动与使用指南

### 1. 启动桌面客户端开发模式
```bash
cd novel-craft
npm run tauri dev
```
首次启动将编译 Rust 桌面外壳并弹出 1280x820 专业工作台窗口。

### 2. 纯浏览器模式（轻量调试）
```bash
cd novel-craft
npm run dev
```
浏览器打开 `http://localhost:1420` 即可实时预览并体验全部功能。

### 3. 配置大模型 (BYOM)
点击右上角 **「模型配置」** 按钮：
- **API Base URL**：如 `https://api.deepseek.com/v1` 或 `https://api.openai.com/v1`
- **API Key**：你的模型密钥（完全存储在本地浏览器/本地存储中，隐私安全）
- **Model**：如 `deepseek-chat` 或 `gpt-4o-mini`
